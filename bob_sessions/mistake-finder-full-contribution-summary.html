Core IBM Bob Skill — .bob/skills/mistake-finder/

SKILL.md — Skill Definition
The main skill instruction set loaded by IBM Bob. Defines two modes of operation with full workflow, guardrails, phase-by-phase instructions, and parallel fan-out rules.
Mode 1: Failure Triage Mode 2: Proactive Review Parallel Subagents Rollback Loop
box.py — Error Parser + Box Renderer
Core engine. Parses Python tracebacks and pytest repr output into structured Finding objects. Generates context-aware suggestions per exception class (SyntaxError, NameError, KeyError, TypeError, ImportError, ZeroDivisionError, …). Renders Unicode ╔╗ or ASCII +-| error boxes.
Dependency-freePython 3.8+
mistake_box.py — CLI Wrapper
Command-line tool: mistake-box python myfile.py. Wraps any command, passes stdout through, intercepts stderr, and prints the box. Also supports --file (static syntax check) and --log (parse a saved CI log).
pytest_plugin.py — Auto-Boxing pytest Plugin
Registers as an entry-point plugin. After every pytest run, produces one mistake box per failing test — no config, no per-project setup. Disable with --no-mistake-box or MISTAKE_BOX=0.
review-checklist.md + report-template.md
Six mistake classes for Mode 2 (logic & boundaries, error handling, concurrency, resources, security, test gaps). Exact output formats for ranked reports in both modes.

How It Works — Architecture

Red tests / changed files
→
Bob activates skill
→
Parallel subagents (read-only)
→
Ranked report (file:line evidence)
→
Fix loop + rollback
→
Green suite
Diagnosis time scales with the slowest failure, not the sum. Every finding requires file:line evidence — no evidence, not a finding.

Voice Agent — voice_agent.py + voice.bat

Say it out loud — full IBM Watson + Granite pipeline
Say "find the mistake in demo math" and the agent: (1) records via ffmpeg/DirectShow mic, (2) sends WAV to Watson STT, (3) resolves the file from the transcript, (4) runs it + prints the box, (5) reads the result back via Watson TTS. Non-find questions are answered by Granite on watsonx.ai.
Watson STT Watson TTS Granite (watsonx.ai) Smart file resolution Push-to-talk + typed mode

Packaging & Installation

pyproject.toml — Installable Python Package
pip install . registers the mistake-box CLI entry-point and the pytest11 plugin entry-point. Works in any interpreter — VS Code Testing panel, PyCharm, terminal, CI. One install, zero per-project config.
.env.example — Credential Template
Template for IBM_API_KEY, IBM_STT_URL, IBM_TTS_URL, WATSONX_URL, WATSONX_PROJECT_ID, WATSONX_MODEL, VOICE_MIC, FFMPEG. Real .env is gitignored.
