# 📸 Bob Task Session Screenshots

This folder contains screenshots of all Bob IDE task sessions, conversations,
and usage summaries captured during the development of **mistake-finder**.

Screenshots here demonstrate the full workflow used across different tasks —
planning, code generation, refactoring, debugging, and testing — and serve as
evidence of Bob IDE usage for submission to the judges.

## What to include here

Screenshot **any** Bob session that shows you using the IDE, for example:

- **Planning** — asking Bob to design the skill architecture or break down tasks
- **Code generation** — Bob writing or scaffolding new files
- **Refactoring** — Bob improving or restructuring existing code
- **Debugging** — Bob finding and fixing mistakes (triage mode in action)
- **Code review** — Bob's proactive review report (review mode)
- **Voice agent** — Bob helping build or fix the voice pipeline
- **Conversation** — any multi-turn session showing your workflow

## How to capture a screenshot

1. In Bob IDE open **Tasks** (left sidebar) to show the task list.
2. Select any task related to this project.
3. Click the **task header** — the session / token-consumption summary appears.
4. Screenshot it as a PNG (make sure the text is clear and readable).
5. Name it something descriptive, e.g.:
   - `task01_skill_planning.png`
   - `task02_voice_agent_build.png`
   - `task03_debug_mic_encoding.png`
   - `task04_code_review_report.png`
6. Drop the PNG into this folder and commit it.

## Tips

- More screenshots = better evidence of your workflow for the judges.
- Cover as many different task types as you can (not just one run).
- The session summary panel showing token usage and task duration is especially
  useful — it proves real IDE usage, not just copy-pasted code.
- Captions are not required but a short filename tells the story on its own.

All screenshots must be committed to the repo before final submission.
