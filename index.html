What does it do?

Two modes — one for broken tests, one for fresh code.

🔴→🟢

Fix Failing Tests

Analyses every failing test in parallel, finds the root cause with file + line evidence, applies the smallest fix, and rolls back if it doesn't work.

🔍

Review Your Code

Six parallel agents check for logic errors, security issues, missing error handling, concurrency bugs, and more — all with evidence or it's not reported.

📦

Friendly Error Boxes

Run any Python file through mistake-box and get a clear, human-readable box showing WHERE, WHAT, and HOW TO FIX — instead of a raw traceback.

🎙️

Voice Mode

Say "find the mistake in demo math" and it finds, explains, and reads back the error. No mic? Type it instead. Powered by Watson STT/TTS.

🔒

Safe by Design

Investigating agents are read-only. Tests are never weakened or deleted. Every finding needs proof. One fix at a time, with full rollback.

⚡

Zero Dependencies

Pure Python 3.8+. No external packages required. Install once with pip install . and it works everywhere — terminal, CI, VS Code, PyCharm.

Get started in 3 steps

Works on Windows, Mac, and Linux. No experience needed.

Download the project

Open a terminal and run: git clone https://github.com/TheLoneSynapse/Bug-Whisperer.git then cd Bug-Whisperer

Install the tool

Run pip install . — this installs the mistake-box command and the pytest plugin automatically.

Use it

In your terminal: mistake-box python yourfile.py — or open IBM Bob and type "Check my code for mistakes."
